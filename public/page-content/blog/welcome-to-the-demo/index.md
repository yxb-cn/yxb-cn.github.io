# Welcome to the Demo Blog

This independent page demonstrates how the template renders **Markdown**,
links, and LaTeX. Replace this article from the local visual editor, or upload
your own `.md` file.

## Markdown

You can use lists, emphasis, headings, and [external
links](https://example.com). Files placed inside this article's folder can be
referenced with a relative path.

## LaTeX

Inline mathematics such as $E[y_{t+1}\mid\mathcal{F}_t]$ works inside a
paragraph. Display equations are also supported:

$$
\widehat{y}_{t+1}
=
\sum_{m=1}^{M} w_{m,t}\widehat{y}_{m,t+1}.
$$

This article and all profile information shipped with the template are
fictional demonstration content.
